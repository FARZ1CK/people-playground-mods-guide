# People Playground: как снова играть с модами (откат на 1.27.17)

В обновлении **1.27.18** Studio Minus включила постоянный safe mode: игра перестала загружать любые C#-моды из папки `Mods`. В **1.28** это добили — в сборке остался только `LuaModLoader`, который наследуется от `EmptyModLoader` и всегда возвращает `false`, то есть список модов пуст при любых действиях. Ни компилятор модов, ни сторонние «фиксы» это не лечат.

Рабочий способ — запускать сборку **1.27.17** из официального депо Steam. Моды, сохранения и контрапшены при этом никуда не деваются.

---

## Сначала прочтите: почему так вышло

Safe mode включили не из вредности. В Мастерской дважды находили вредоносные моды: они выходили из песочницы, лезли в файлы на диске, в данные Steam Cloud других игр и в сохранённые логины. Вернув старую версию, вы снова включаете загрузку **всех** модов, включая те, что остались в подписках.

Поэтому:

- не подписывайтесь на новые и незнакомые моды;
- включите в настройках игры **Reject shady code** (`RejectShadyCode` в `config.json`);
- мод, в папке которого лежат `.dll`, `.exe` или инструкции «отключи защиту», — повод сразу его удалить;
- нормальный мод — это `.cs`-скрипты, картинки и звуки.

## Шаг 1. Проверьте папку игры на сторонние загрузчики

Откройте папку игры (Steam → ПКМ по игре → Управление → Просмотреть локальные файлы) и поищите:

- рядом с `People Playground.exe`: `winhttp.dll`, `version.dll`, `doorstop_config.ini`;
- в `People Playground_Data\Managed`: dll-файлы, дата которых сильно новее соседних;
- в `People Playground_Data` папки помимо `Managed`, `Plugins`, `Resources`, `StreamingAssets`.

Игра ничего из этого не поставляет. Такие файлы ставят «фиксы модов» и недобросовестные моды, и они грузятся при каждом запуске, даже в safe mode. Уберите их из папки игры (лучше в отдельную папку, а не в корзину) и прогоните полную проверку антивирусом.

---

## Шаг 2. Скачайте сборку 1.27.17 через консоль Steam

1. `Win + R` → `steam://open/console` → Enter. В Steam откроется вкладка **CONSOLE**.
2. В поле внизу вставьте строку и нажмите Enter:

   ```
   download_depot 1118200 1118201 1841632748164576618
   ```

3. Прогресса в процентах не будет — это нормально. Ждите строку вида:

   ```
   Depot download complete : "C:\Program Files (x86)\Steam\steamapps\content\app_1118200\depot_1118201"
   ```

Это 64-битная версия игры (~435 МБ). Для 32-битной Windows депо другое — `1118202`.

---

## Шаг 3. Запускайте старую сборку

Самый простой и безопасный для обновлений вариант — запускать exe из папки депо напрямую:

```
C:\Program Files (x86)\Steam\steamapps\content\app_1118200\depot_1118201\People Playground.exe
```

Steam при этом должен быть запущен (игра берёт оттуда Steamworks). Steam не обновляет папку `content`, поэтому safe mode туда не вернётся.

### Если хочется запускать кнопкой Play

Steam → ПКМ по игре → Свойства → Общие → Параметры запуска:

```
"C:\Program Files (x86)\Steam\steamapps\content\app_1118200\depot_1118201\People Playground.exe" %command%
```

Кавычки должны быть обычными прямыми (`"`). Steam обновит свою копию игры, но запускать будет старую.

## Шаг 4. Подключите моды, контрапшены и настройки

В папке `depot_1118201` создайте ссылки на ваши данные из основной установки — тогда моды останутся в одном месте и ничего не придётся дублировать. В командной строке (обычная, без администратора):

```
mklink /J "C:\Program Files (x86)\Steam\steamapps\content\app_1118200\depot_1118201\Mods" "C:\Program Files (x86)\Steam\steamapps\common\People Playground\Mods"
mklink /J "C:\Program Files (x86)\Steam\steamapps\content\app_1118200\depot_1118201\Contraptions" "C:\Program Files (x86)\Steam\steamapps\common\People Playground\Contraptions"
```

И скопируйте в `depot_1118201` файлы:

- `config.json` (настройки и горячие клавиши);
- `externalactives` (какие моды включены);
- `stats`.

Если ссылки делать не хотите — просто скопируйте папку `Mods` в `depot_1118201`. Ссылка удобнее: моды остаются в единственном экземпляре и не расходятся по двум папкам.

---

## Шаг 5. Проверьте, что всё работает

В главном меню версия должна быть **1.27.17** и без пометки `[SAFE MODE]`. В списке модов появятся ваши моды. Если у какого-то мода написано `ERROR` — нажмите **Recompile**.

Проверка по логам: в папке `depot_1118201\Logs` свежий `*-Menu.log` содержит строки `Attempt load mod at Mods\...` и `Loaded mod: ...`.

---

## Если что-то пошло не так

- **Версия всё равно 1.28 / safe mode.** Значит, запускается не тот exe: проверьте путь в ярлыке или в параметрах запуска.
- **Список модов пуст.** Проверьте, что папка `Mods` доступна из `depot_1118201` (ссылкой или копией) и что в ней лежат папки с `mod.json`.
- **`Could not compile mod ...` с «suspicious identifier».** Мод несовместим с 1.27.17 или использует запрещённые вызовы. Часть таких модов оживает после Recompile, часть — нет.
- **Мод просит файл, которого нет** (например, `Prostheses_settings.json`). Это внутренняя ошибка мода, игра тут не виновата.
- **Steam обновил основную установку.** На папку депо это не влияет — она не в манифесте.

---

## Как всё вернуть назад

1. Очистите параметры запуска (если задавали).
2. Запускайте игру обычной кнопкой Play — это снова 1.28 без модов.
3. Папку `steamapps\content\app_1118200\depot_1118201` можно удалить, чтобы освободить ~435 МБ.
4. Если хотите чистую установку — Свойства → Установленные файлы → Проверить целостность файлов игры.

Ссылки `mklink /J` при удалении папки депо исчезнут вместе с ней, оригинальные `Mods` и `Contraptions` не пострадают.

## FAQ

**Моды и сохранения пропали?** Нет. Safe mode только блокирует загрузку, файлы на месте. Контрапшены — в `Contraptions`, включённые моды — в `externalactives`.

**Достижения работают?** Да, старая сборка остаётся той же игрой в Steam.

**Новые моды из Мастерской можно ставить?** Мастерская переведена на контрапшены, моды оттуда больше не раздаются. Рассчитывайте на те, что уже скачаны (и на локальные `Mods`).

**Можно ли просто «пропатчить» 1.28?** Нет. В ней нет рабочего загрузчика C#-модов, патчить нечего — именно поэтому нужен откат.

**Это бан?** Нет. `download_depot` — штатная команда консоли Steam, игра одиночная. Но старые версии разработчик не поддерживает.
